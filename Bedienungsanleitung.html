Was ist das?

AMK Gästeliste PRO ist das Gästelisten-System für die Tour „AnnenMayKantereit · Live 2026". Es läuft komplett offline im Browser, ganz ohne eigenen Server oder Internetverbindung — das Herzstück ist die Datei gaesteliste.html mit den drei Bereichen Verwaltung, Einladen und Einlass, ergänzt um einen Bereich Ticket-Zugang (Demo), der zeigt, wie ein Gast künftig selbst seinen Zugang samt Sitz-/Platzwahl bedienen könnte.

Diese Anleitung führt Schritt für Schritt durch alle Bereiche und zeigt echte Bildschirmfotos aus dem Tool.

Aufbau wie gewohnt: Bildschirmaufbau, Spalten und Begriffe folgen der bisherigen Gästelisten-Tabelle von Landstreicher Booking — gleicher Kopfblock, gleiche Spaltenreihenfolge, gleiche Bezeichnungen (Steh, Sitz, Aftershow, Kat 4, AAA, F/F, Foto, Referenz/Medium, c/o, Pool). Wer die Tabelle kennt, findet sich sofort zurecht. Einzelheiten in Kapitel 11.

Wichtig — was ist DEMO? Der gesamte Bereich „Ticket-Zugang" inklusive Saalplänen, Platzwahl und „Kauf"-Ablauf (Kapitel 4) ist eine Simulation zu Vorführzwecken. Es werden keine echten Tickets ausgestellt, keine echten Zahlungen verarbeitet und keine echten Saalpläne verwendet. Echte Tickets für AnnenMayKantereit · Live 2026 gibt es ausschließlich über den offiziellen Ticketing-Partner krasserstoff. Eine tatsächliche technische Anbindung existiert in diesem Paket nicht — welche Fragen dafür vorab zu klären sind, steht im separaten Fragenkatalog_Landstreicher_krasserstoff.html (siehe Kapitel 8). Alle anderen Kapitel (Verwaltung, Einladen, Einlass, Exporte) sind die echte, produktive Funktion des Tools.

1 Schnellstart Windows & Mac

Über den Link geöffnet? Dann ist nichts zu tun — das Tool läuft bereits im Browser, auf Windows, Mac, iPhone und Android. Die Kapitel 1 und 2 beschreiben nur die Offline-Variante mit dem heruntergeladenen Paket. Am Handy lässt sich die Seite über Teilen → „Zum Home-Bildschirm" wie eine App ablegen.

Das Tool ist eine gewöhnliche HTML-Datei und läuft unter Windows wie unter macOS im Browser — ohne Installation. Für beide Systeme liegen fertige Starter bei:

Weg A — Doppelklick auf gaesteliste.html

Der einfachste Weg für den täglichen Einsatz. Einfach im Ordner auf gaesteliste.html doppelklicken — das Tool öffnet sich im Standard-Browser (file://…) und funktioniert vollständig offline, auch ganz ohne Internetverbindung. Alle Eingaben werden lokal im Browser gespeichert (siehe Kapitel 7 „Datensicherung").

Weg B — Start_Windows.bat

Startet einen kleinen lokalen Server auf diesem PC und öffnet das Tool im Browser unter http://localhost. Vorteil: Die vollen PWA-Funktionen (als App installieren, Offline-Cache) funktionieren technisch nur über http://localhost oder https — nicht bei einfachem Doppelklick. Ist auf dem PC kein Python installiert, öffnet das Skript stattdessen automatisch die Datei direkt wie bei Weg A.

Weg C — Mac (Start_Mac.command)

Am Mac genügt ebenfalls der Doppelklick auf gaesteliste.html; das Tool öffnet sich in Safari oder Chrome, alle Funktionen inklusive Speichern stehen zur Verfügung. Wer zusätzlich die Original-Schriften und die PWA-Funktionen möchte, startet Start_Mac.command — das Skript sucht sich einen freien Port, startet den kleinen Server und öffnet den Browser von selbst. Ist auf dem Mac kein Python vorhanden, öffnet es einfach die Datei direkt.

Rein kosmetisch: Beim Doppelklick lädt Safari die Schriftarten nicht aus dem Netz nach und verwendet die Systemschrift. Inhalt, Bedienung und gespeicherte Daten sind identisch — mit der Safari-Engine geprüft.
Beim ersten Start am Mac: macOS lässt heruntergeladene .command-Dateien nicht sofort per Doppelklick zu („nicht überprüft"). Einmalig genügt: Rechtsklick bzw. Ctrl + Klick auf die Datei → Öffnen → im Hinweisfenster nochmals Öffnen. Danach klappt der normale Doppelklick. Startet die Datei gar nicht, hilft einmalig im Terminal: chmod +x "/Pfad/zum/Ordner/Start_Mac.command". Wer sich das sparen will, nimmt Weg A — der funktioniert immer und ohne Rückfrage.
Für die reine Tagesarbeit reicht Weg A auf beiden Systemen völlig aus. Die Server-Starter lohnen sich, wenn das Tool als eigene App-Kachel installiert werden soll oder mehrere Geräte im selben WLAN zugreifen sollen (siehe Kapitel 2).

2 Handy/Tablet im WLAN (iPhone, iPad, Android)

Auf iPhone, iPad oder Android lässt sich das Paket nicht direkt aus der Dateien-App heraus starten — das ist eine Beschränkung der Geräte, kein Fehler des Tools. Der Weg dorthin führt über den Server-Starter auf einem PC oder Mac im selben WLAN:

  • Windows: Start_Server_Handy.bat
  • Mac: Start_Server_Handy_Mac.command (beim ersten Start Rechtsklick → „Öffnen", siehe Kapitel 1)

Beide zeigen eine Adresse wie http://192.168.x.x:8765 an — diese Adresse am Handy oder Tablet im Browser eingeben.

Voraussetzung: Der PC bzw. Mac mit dem Server muss dabei eingeschaltet bleiben und im gleichen WLAN sein wie das Handy/Tablet. Beim ersten Start ggf. die Firewall-Abfrage bestätigen (Windows-Firewall bzw. macOS-Rückfrage „eingehende Verbindungen erlauben").

Auf dem Home-Bildschirm installieren

  • iOS (iPhone/iPad): Seite im Safari-Browser öffnen → Teilen-Symbol → „Zum Home-Bildschirm".
  • Android/Edge: Seite öffnen → Menü (⋮) → „App installieren" bzw. „Zum Startbildschirm hinzufügen".

Ehrliche PWA-Grenze

Voll-Offline-Betrieb (Installation als App mit eigenem Icon und Offline-Cache) funktioniert technisch nur über https oder localhost. Der WLAN-Zugriff per http://192.168.x.x:8765 ist kein localhost und kein https — deshalb greifen dort die vollen PWA-Funktionen (Installierbarkeit, Offline-Cache) nur eingeschränkt oder gar nicht. Die Seite selbst funktioniert trotzdem ganz normal im Browser, solange der Server auf PC oder Mac läuft.

Kurz gesagt: Am Handy im WLAN braucht es immer den laufenden Server auf PC oder Mac im Hintergrund — es ist kein eigenständiger Offline-Modus wie direkt am Rechner.

3 Die drei Modi + Ticket-Tab

Oben im Tool wechseln vier Tabs zwischen den Bereichen: Verwaltung, Einladen, Einlass und Ticket.

Menüleiste und Bereichsliste

Ganz oben liegt eine Menüleiste mit sechs Menüs: Liste, Show, Exporte, Daten, Ansicht und Hilfe. Mit der Maus reicht Zeigen, dann klappt das Untermenü auf; am Handy und Tablet tippt man den Namen an. Darüber erreicht man alles, was es auch an anderer Stelle gibt — vom neuen Gast über die Exporte bis zu den Einstellungen.

Am breiten Bildschirm steht links zusätzlich eine Bereichsliste: oben die vier Bereiche, darunter Sprungmarken in den gerade geöffneten Bereich, unten der Schnellzugriff mit Einstellungen und Liste einlesen. Ist das Fenster schmal, treten wieder die vier Reiter oben an ihre Stelle.

Verwaltung

Der Hauptarbeitsbereich für das Tourmanagement: aktive Show wählen, Kopfblock pflegen (Kapazitäten, Gast Limit, Pool-Kontingente, Kontakte für Rücksprachen, Vorjahresvergleich), Anträge freigeben oder ablehnen, die Gästeliste als Tabelle durchsehen und direkt bearbeiten, Liste finalisieren und Exporte anstoßen.

Der Kopfblock steht — wie in der gewohnten Tabelle — über der Liste: links Datum, Ort - Venue, Kapazität Stehplätze, Kapazität Sitzplätze, Family-&-Friends-Bereich und die Kontakte für Rücksprachen (AP LSB, AP Tour, AP ÜV GL); in der Mitte show, no show, Gast Limit, verbraucht, übrig; rechts die Pool-Tabelle mit Kont, Pool, verbraucht, übrig und darunter der Vorjahresvergleich.

Die Gästeliste steht darunter als Tabelle mit genau den gewohnten Spalten. Die Mengenfelder (Steh, Sitz, Aftershow, Kat 4, AAA, F/F, Foto) lassen sich direkt in der Zeile ändern — wie in der Tabelle. Über „Ansicht" kann zwischen Tabelle und Karten gewechselt werden, über „Spalten" zwischen Alle und Nur benutzte (blendet leere Mengenspalten aus, so wie in der Vorlage bei einer reinen Stehplatz-Show die Spalten Aftershow und Kat 4 ausgeblendet sind).

Ganz oben steht die Auswahl „Künstler / Band" mit allen von Landstreicher Booking vertretenen Acts. Jeder Künstler hat einen eigenen Arbeitsbereich mit eigenen Shows und Gästen — Einzelheiten in Kapitel 10.

Weiter unten im Verwaltungs-Tab liefert das Statistik-Dashboard auf einen Blick die Verteilung über Steh, Sitz, Aftershow, Kat 4 und die Zusatzausweise, die Pool-Auslastung gegen das jeweilige Kontingent sowie Einlass-Quote und Aftershow-Anteil der aktiven Show. Direkt darunter zeigt die Kontingent-Matrix alle Pools gegen alle Shows der Tour — ein Klick auf eine Zeile klappt die zugehörigen c/o-Personen auf, eine Zelle zeigt Ausnahmen vom Standard-Kontingent.

Einladen

Der reduzierte Bereich für die c/o-Personen: nach Auswahl der eigenen Person (tour-internes Vertrauensmodell, keine Login-Pflicht) sieht man nur das eigene Kontingent und die eigenen Gäste — bewusst auf ein 15-Sekunden-Ziel getrimmt: Person wählen, „+ Gast", fertig.

Einlass

Für das Einlass-Personal am Abend: große, gut antippbare Zeilen je Gast, Suche und Filter nach Platzart bzw. Zusatzausweis, Anzeige „X von Y da" bei Zeilen mit mehreren Personen. Jedes Häkchen zählt oben im Kopfblock auf show und no show ein — dieselben beiden Zahlen wie in der gewohnten Tabelle. Der Einlass-Tab zeigt nur finalisierte Shows — eine Liste muss also vorher in der Verwaltung finalisiert werden (siehe Kapitel 5), sonst bleibt die Auswahl leer.

Ticket-Tab

Zeigt und verwaltet die Ticket-Zugänge (Demo) der gewählten Show: neuen Zugang erstellen, bestehende Zugänge per Link/Mail/QR-Code weitergeben, Details ansehen oder widerrufen. Der Kasten Sammel-Mailout darüber erledigt den Versand in einem Rutsch: Zugänge für alle offenen Zeilen anlegen (Plätze und E-Mail kommen aus der Gästeliste), Mailout-Liste als CSV für den Serienversand ziehen und den Versandstand setzen. Näheres dazu in Kapitel 4.

4 Ticket-Zugang (Demo)

Zur Erinnerung: Dieser gesamte Bereich ist eine Simulation. Kein echtes Ticketing, keine echte Zahlung, keine echten Saalpläne — Zweck ist es, dem Tourmanagement und Landstreicher Booking zu zeigen, wie ein künftiger Gast-Zugang aussehen könnte.

Im Ticket-Tab (Verwaltung-Seite) lässt sich pro Show für einen Gast ein Ticket-Zugang erstellen: E-Mail eintragen, Modus wählen (Kontingent = 0 €, oder Kauf-Demo), maximale Plätze festlegen. Der erzeugte Zugang erscheint in der Tabelle mit den Aktionen Link (Adresse kopieren), Mail (mailto-Versand ans E-Mail-Programm), QR (QR-Code zum Scannen), Details und Widerrufen.

Gast-Sicht — Kontingent/GA (Stehplatz-Bereiche)

Öffnet der Gast seinen Link (gast.html?token=…), sieht er je nach Venue entweder reine Kategorie-Bereiche mit Stepper (bei Stehplatz-Venues wie Festival-Parks) …

Gast-Sicht — Sitzplan (Hallen/Stadien)

… oder bei Hallen/Stadien mit fester Bestuhlung einen Demo-Saalplan mit Legende (frei/belegt/gewählt), Block-Auswahl, Warenkorb-Zeile und dem Button „Beste freie Plätze wählen".

Am Handy

Die Gast-Seite ist für schmale Bildschirme optimiert — genauso, wie ein Gast sie am eigenen Smartphone öffnen würde.

Der Hinweis „Demo" oben rechts auf der Gast-Seite bleibt in dieser Simulation immer sichtbar. QR-Codes und Links funktionieren nur auf demselben Gerät bzw. im selben lokalen Netzwerk, solange der Server läuft (siehe Kapitel 2) — es gibt keinen echten Server-Versand.

5 Exporte

Finalisierungs-Pflicht: Alle Exporte sind erst möglich, nachdem die Gästeliste einer Show über den Button „Liste finalisieren" eingefroren wurde. Vorher zeigt die Verwaltung „Nicht final — Exporte gesperrt". Nach der Finalisierung zählen weitere Änderungen als Nachtrag und müssen erneut exportiert werden.

Über den Toolbar-Button Exporte öffnet sich der Export-Dialog. Der erste Eintrag „(e) Tabelle im gewohnten Aufbau" ist bewusst auch ohne Finalisierung möglich — er ist der Zwischenstand für die vertraute Tabelle, nicht die Abendkassen-Fassung.

6 Optionen

Über das Zahnrad-Symbol „Einstellungen" oben links öffnet sich der Optionen-Dialog:

  • Theme Hell/Dunkel — das Tool startet standardmäßig hell, also nah am gewohnten Bild der bisherigen Tabelle. Für den Abend und den Einlass lässt sich jederzeit auf das dunkle Roadcase-Design umschalten.
  • Schriftgröße S/M/L — für unterschiedliche Bildschirme und Lesegewohnheiten am Einlass.
  • Einfach/Profi — der Einfach-Modus blendet Detailfunktionen rein visuell aus und reduziert die Oberfläche auf das Nötigste; der Profi-Modus zeigt alle Funktionen.

Suche, Filter und Mehrfachauswahl

In der Gästeliste (Verwaltung) durchsucht das Suchfeld Name, weitere Personen, E-Mail, Referenz/Medium, c/o und Notiz gleichzeitig. Darunter lassen sich Status (angefragt/genehmigt/abgelehnt/final), Spalten (Steh, Sitz, Aftershow, Kat 4, AAA, F/F, Foto), Pools sowie „nur Aftershow", „nur Nachtrag" und „Mailout offen" als Filter-Chips kombinieren. Über Kontrollkästchen können mehrere Zeilen gleichzeitig ausgewählt und per Mehrfach-Aktion genehmigt, abgelehnt, einem anderen Pool zugeordnet, als Mailout versendet markiert oder gelöscht werden (nur solange die Liste nicht finalisiert ist).

Undo

Nach Aktionen wie Genehmigen, Ablehnen, Löschen oder Check-in erscheint kurz eine Rückgängig-Möglichkeit — ein Sicherheitsnetz gegen Fehlklicks im hektischen Tour-Alltag.

7 Datensicherung

Alle Daten werden automatisch im Browser gespeichert (localStorage) — der Zeitpunkt des letzten Speicherns steht dezent im Kopfbereich („Gespeichert HH:MM"). Diese automatische Speicherung ist bequem, aber nicht unzerstörbar: Eine Browser-Bereinigung, ein Cache-Reset oder ein Gerätewechsel kann den Stand löschen.

Deshalb wichtig: Regelmäßig über den Toolbar-Button JSON-Export eine Sicherungsdatei erzeugen und in den Ordner _daten\ ablegen. Das Tool zeigt dazu einmal pro Sitzung einen dezenten Erinnerungshinweis.

Ein JSON-Export enthält den kompletten Stand über alle Shows. Über JSON-Import lässt sich eine solche Datei wieder einspielen — vor dem Überschreiben fragt das Tool immer mit der genauen Anzahl an Gästen und Shows zur Bestätigung nach, um Datenverlust durch Versehen zu vermeiden.

8 krasserstoff heute & morgen

Heute ist krasserstoff als offizieller Ticketing-Partner für AnnenMayKantereit · Live 2026 zuständig für echte Tickets, echte Zahlungen und echte Saalpläne. Dieses Paket bildet lediglich eine mögliche künftige Gast-Erfahrung nach — es besteht aktuell keine technische Anbindung an krasserstoff.

Für eine echte Anbindung (z. B. automatischer Ticketversand, echte Sitzplandaten, Zahlungsabwicklung) müssen vorab technische und organisatorische Fragen mit Landstreicher Booking und krasserstoff geklärt werden. 9 Datenschutz

E-Mail-Adressen von Gästen sind personenbezogene Daten und werden im Tool nur für Ticket-Zugänge erfasst (Kapitel 4) — nur mit Einwilligung der betroffenen Person eintragen. Die E-Mail-Adressen erscheinen sowohl in der Ticket-Zugangstabelle als auch im JSON-Gesamtexport.

Über die Funktion „Show-Daten löschen" in der Verwaltung lassen sich alle Gäste, Ticket-Zugänge und E-Mail-Adressen einer Show vollständig entfernen. Statistik-Zahlen bleiben dabei anonym erhalten — es werden nur Namen und personenbezogene Kontaktdaten gelöscht, nicht die aggregierten Kennzahlen.

Nach Abschluss einer Show empfiehlt es sich, die Show-Daten zeitnah zu löschen, sobald sie nicht mehr für Nachfragen benötigt werden.

10 Künstler/Band wählen & Shows anlegen

Das Tool ist nicht auf eine einzige Band festgelegt. Ganz oben im Tab Verwaltung steht das Auswahlfeld „Künstler / Band · Landstreicher Booking". Ein Klick darauf klappt die Liste aller von Landstreicher Booking vertretenen Künstler und Bands auf — alphabetisch sortiert, 15 Einträge auf einen Blick, der Rest per Scrollen erreichbar. Wer schneller ist: einfach die ersten Buchstaben ins Suchfeld tippen, die Liste filtert sofort mit. Bedienbar auch komplett per Tastatur (Pfeiltasten, Pos1/Ende, Enter zum Übernehmen, Esc zum Schließen).

Was beim Wechsel passiert

Jeder Künstler hat einen eigenen, vollständig getrennten Arbeitsbereich: eigene Shows, Gäste, Kontingente, Ticket-Zugänge und Exporte. Beim Wechsel wird der aktuelle Stand automatisch gespeichert — es geht nichts verloren, und Daten verschiedener Künstler können sich nicht vermischen. Der Name im Kopf der Seite, die Dateinamen der Exporte, die Druckliste und der Text der Ticket-Mail übernehmen den gewählten Künstler automatisch.

Im Feld „Tour / Anlass" direkt darunter lässt sich die Tour eintragen (z. B. „Arena 2027"). Sie erscheint dann im Seitenkopf und in der Fußzeile der Drucklisten.

Kommende Shows und Archiv

Das Tool startet immer bei der nächsten anstehenden Show. Im Auswahlfeld „Aktive Show" stehen oben die kommenden Shows (nach Datum), darunter unter „Archiv · gespielte Shows" alle bereits gespielten — neueste zuerst. Über das Archiv lassen sich vergangene Veranstaltungen jederzeit nachschlagen: Gästeliste, Check-in-Stände, Statistik und Exporte bleiben vollständig erhalten. Der Showtag selbst zählt noch als kommend, es rutscht also nichts mitten in der Veranstaltung ins Archiv. Dieselbe Zweiteilung gilt im Ticket-Tab, im Einlass und in der Show-Verwaltung.

Shows anlegen

Ein frisch gewählter Künstler startet mit leerem Tourplan. Über „+ Erste Show anlegen" (bzw. später über Stammdaten & Einstellungen → „Shows verwalten") werden Datum, Stadt und Spielstätte eingetragen. Ab der ersten Show stehen Gästeliste, Freigabe, Finalisierung, Einlass und alle Exporte genauso zur Verfügung wie bei AnnenMayKantereit. Shows lassen sich dort auch nachträglich ändern oder löschen — löschen ist nur möglich, solange keine Gäste oder Ticket-Zugänge daran hängen (sonst zuerst Kapitel 9 „Datenschutz").

Demo-Grenze: Die vereinfachten Saalpläne des Ticket-Bereichs existieren nur für die zwölf hinterlegten AnnenMayKantereit-Spielstätten. Bei neu angelegten Shows anderer Künstler funktionieren Gästeliste, Einlass und alle Exporte vollständig — die Sitzplatzauswahl der Gast-Ansicht meldet dort sauber, dass für diese Show kein Saalplan hinterlegt ist.

11 Aufbau wie die gewohnte Gästelisten-Tabelle

Das Tool ist bewusst so gebaut, dass niemand umlernen muss. Kopfblock, Spalten, Reihenfolge und Begriffe entsprechen der bisherigen Gästelisten-Tabelle von Landstreicher Booking.

Die Spalten

SpalteBedeutung im Tool
showWie viele Personen dieser Zeile beim Einlass da waren (z. B. „2/3"). Wird beim Abhaken im Einlass automatisch gesetzt und zählt oben auf show und no show ein.
Name · VornameWie gewohnt, Name zuerst.
E-MailWie gewohnt — und zusätzlich die Grundlage für Ticket-Zugang und Mailout.
Steh · Sitz · Aftershow · Kat 4Plätze. Ihre Summe ist die Personenzahl der Zeile und zählt auf das Gast Limit — genau wie die Formel verbraucht = Steh + Sitz + Aftershow + Kat 4 in der Tabelle. „Aftershow" meint hier den Aftershow-only-Platz.
AAA · F/F · FotoZusatzausweise. Sie zählen — wie in der Tabelle — nicht auf das Gast Limit.
Referenz/MediumMedium, Partner oder Anlass der Einladung. Freitext wie gewohnt.
c/oAuf wen der Gast läuft. Im Tool eine gepflegte Auswahl statt Freitext — dadurch gibt es je c/o-Person ein eigenes Kontingent und eine eigene Auswertung.
PoolPflichtfeld wie in der Vorlage („Pool (IMMER AUSWÄHLEN)"). Voreingestellt sind Band, Management, Landstreicher Booking, Presse, Präsentator*in, Musiker*innen, Support und Crew; Kontingente und weitere Pools lassen sich unter Stammdaten & Einstellungen → „Pools bearbeiten" pflegen.
NotizWie gewohnt.
MailNeu: zeigt, ob der Mailout für diese Zeile schon raus ist. Ersetzt die handgesetzte Merkzeile „Mailout bis hier versendet" — im Export steht sie trotzdem weiterhin drin.
StatusNeu: angefragt / genehmigt / abgelehnt / final. Damit lässt sich die Freigabe sauber trennen, statt Zeilen zu färben oder zu löschen.

Der Kopfblock

Über der Liste stehen dieselben Angaben wie im Kopf der Tabelle, nur klickbar statt als Formel:

  • Show — Datum, Ort - Venue, Kapazität Stehplätze, Kapazität Sitzplätze (jeweils mit der aktuell vergebenen Zahl daneben, rot bei Überschreitung), Family-&-Friends-Bereich, Kontakte für Rücksprachen (AP LSB, AP Tour, AP ÜV GL mit Name und Mobilnummer).
  • Zählung — show, no show, Gast Limit, verbraucht, übrig; dazu das Vertragskontingent zur Kontrolle.
  • Pools — die Tabelle Kontingent · Pool · verbraucht · übrig. Ein Klick auf eine Zeile öffnet das Kontingent, auch als Ausnahme nur für diese Show.
  • Vorjahresvergleich — die Zeilen Tag 1 / Tag 2 (Überschrift und Bezeichnungen frei änderbar); darunter der Vergleich zum aktuellen Stand.

Was zusätzlich dazukommt

  • Freigabe-Weg statt Farbmarkierungen: angefragt → genehmigt/abgelehnt → final.
  • Finalisierung mit Versionsnummer — die Abendkasse bekommt nie einen veralteten Stand.

12 Bestehende Gästeliste übernehmen

Eine Liste, die heute schon in einer Tabelle steht, muss nicht abgetippt werden. Dafür gibt es eine Importvorlage im gewohnten Aufbau.

So geht es

  1. Im Werkzeug links unter Schnellzugriff auf Liste einlesen. (Ist für eine Show noch kein Gast angelegt, steht der Knopf zusätzlich direkt bei der leeren Liste.)
  2. Importvorlage herunterladen · CSV — die Datei heißt Importvorlage_Gaesteliste.csv und liegt auch dem Paket bei.
  3. Die Vorlage in Excel oder Numbers öffnen, die bestehende Liste hineinkopieren, die zwei Beispielzeilen überschreiben und die Datei wieder als CSV speichern. Bleiben die Beispielzeilen stehen, werden sie beim Einlesen übergangen.
  4. Im Werkzeug auf Ausgefüllte Datei einlesen und die Datei auswählen.

Was beim Einlesen passiert

  • Die Gäste landen in der aktiven Show und stehen dort als genehmigt.
  • Pool und c/o werden am Namen erkannt; was es noch nicht gibt, wird angelegt.
  • Namen, die in dieser Show schon stehen, werden übersprungen — es entstehen keine Dubletten.
  • Vorhandene Gäste bleiben unverändert; es kommen nur neue Zeilen dazu.
  • Die Spalten show und Mailout werden übergangen, Summen- und Zwischenzeilen ebenso.

Gut zu wissen

  • Der Trenner darf Semikolon, Komma oder Tabulator sein — das erkennt das Werkzeug selbst.
  • In den Spalten Steh, Sitz, Aftershow, Kat 4, AAA, F/F und Foto steht jeweils eine Anzahl; leer bedeutet 0.
  • Der umgekehrte Weg ist der Export „(e) Tabelle im gewohnten Aufbau · CSV" — beide passen zusammen.
